# Changelog

## 0.1.0 — 2026-10-04

- One standalone HTML interface and one user-owned Markdown diary main file.
- Continuous content board, yearly overview, hierarchical tags and daily entries.
- Markdown backup and restore that adds missing dates without replacing existing dates.
- English by default, with Chinese switching and unchanged user-written content.
- Local image backgrounds, brightness, resizable panels and page-based reminders.
- Shared development and distribution sources; offline scripts and styles.

Publication status and validation results are recorded in `docs/release-v0.1.0.md`.
