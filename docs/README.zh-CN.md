# Colorbar Diary 发布副本

本目录完全独立于原测试版。首次进入默认英文，顶部和连接主文件页面均可切换中文；切换前保存输入，切换后重新载入。自定义标签和日记正文保持原文，Markdown 的中文格式标记继续兼容旧文件。

## 使用

- 直接使用：打开 `dist/releases.json` 中 latest 对应的 HTML，建议桌面 Chrome／Edge，选择或新建 Markdown 主文件。
- 从源码运行：Node.js 20+，在本目录执行 `npm start`，访问 `http://127.0.0.1:4327`。
- 日记在本目录新建的 `data/` 下保存，不读取原测试版的 `../data/`。
- 验证：`npm test`；构建：`npm run build:static`；清单检查：`npm run audit`。

## 文件按钮

| 英文 | 中文 | 功能 |
| --- | --- | --- |
| Connect file | 连接主文件 | 选择、新建或重新授权日记文件 |
| Export unsaved draft | 导出未保存草稿 | 下载当前内容，保存失败时也可保留输入 |
| Reload file | 重新导入 | 重新读取外部修改后的主文件；确认后可能丢弃未保存修改 |
| Backup | 备份 | 下载带日期的 Markdown 副本 |
| Restore | 恢复 | 添加备份中缺少的日期，现有日期整天跳过 |

背景图片不进入 Markdown。测试服务器把图片副本存入自己的 data/bg_pic_*.jpg；单 HTML 优先引用已授权的本地图片，文件或权限失效时回到黑色。0–100% 背景亮度与面板不透明度独立。

提醒需要页面运行及声音权限，不是操作系统闹钟。关闭页面、休眠后不补响过去的提醒。

## 隔离与发布范围

没有复制私人日记、背景照片、用户截图、旧备份和历史归档。展示截图来自自动化测试生成的虚构文字。没有上传 GitHub，没有选择许可证；正式发布前再补许可证和仓库设置。

原测试版文件保持不变。当前交互记录写入本目录的需求草案更新日记，不写入原项目文件。
