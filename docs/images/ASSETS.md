# README image assets

`english-rich.png` is an actual application screenshot with entirely fictional
entries, rendered from a temporary Markdown diary. It does not contain user data.
Recreate it with `node scripts/capture-showcase.cjs` after installing Playwright
as described in the README. No application source changes are needed.

`blue-hour-wallpaper.png` is an original AI-generated wallpaper made with the
built-in image generation tool on 2026-10-04 for this project. The screenshot
uses the app's background brightness control to keep text readable.

Generation prompt:

> Create an original photorealistic desktop wallpaper, wide landscape aspect ratio 16:10. A tranquil alpine lake at blue hour, distant layered mountain silhouettes, wisps of mist above still water, a delicate soft mauve glow on the horizon, a small dark pine grove at the far edge. Elegant cinematic nature photography, slate blue, deep teal, muted indigo, very restrained warm lavender light. Low luminance and soft contrast suitable behind colorful diary text, no bright sun, no white highlights, no buildings, no people, no text, no logos. Broad quiet areas across the image, subtle natural texture. Only the wallpaper, no computer UI, no frame.
